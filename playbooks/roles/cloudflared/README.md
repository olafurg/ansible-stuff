# Cloudflared

Using the free version of Cloudflare Gateway to configure access policies on the network. With Pi-hole using Cloudflare Gateway as the upstream DNS provider.

Main instructions here:
https://docs.pi-hole.net/guides/dns/cloudflared/

_Note that using this on a UniFi network, it's important to disable any content filtering on that device, since that bypasses the upstream filtering it seems._
